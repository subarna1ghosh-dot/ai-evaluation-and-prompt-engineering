## Core Evaluation Rubric
- **Instruction Following:** Strict adherence to formatting rules, word limits, and negative constraints.
- **Factual Accuracy & Grounding:** Verification of claims against reliable sources without unsupported assumptions.
- **Language & Localization Quality:** Natural Bengali/English phrasing with zero machine-translation artifacts.
